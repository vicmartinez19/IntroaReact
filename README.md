# Actividad 1: Tarjetas de Presentación (Intro a React y Componentes)

## 📌 Descripción del Proyecto
Aplicación web moderna construida con **React 18** y **Vite** para demostrar los fundamentos esenciales de la biblioteca:
- Creación de proyectos con Vite y entorno de desarrollo ultra-rápido.
- Componentes funcionales (`function Tarjeta(props)`).
- Sintaxis **JSX** (expresiones entre llaves `{}`, anidamiento y etiquetas autocontenidas).
- Paso de **Props** dinámicas e inmutables para renderizar múltiples perfiles.
- Configuración de rutas relativas con `base: './'` en `vite.config.js` para compatibilidad absoluta con **GitHub Pages** (evitando errores 404 al cargar archivos `.js` y `.css`).
